# Contributing

Use fabricated inputs and run the CPU checks documented in the README. Describe
any change to the scientific method, its validation, and the relevant cohort
in the review.

Keep patient files, identifiers, individual predictions, private folds,
trained artifacts, private service links and infrastructure locations out
of files, commit metadata, issues and pull requests. Inspect staged files and
Git history before release. Use aggregate results and project-authored synthetic
fixtures for examples.

The existing research archive records the executed methodology and artifacts.
Report code changes against the precise revision tested. Contact the authors
about reuse or redistribution of this code.
